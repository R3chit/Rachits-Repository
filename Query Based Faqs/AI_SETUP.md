# AI Brain Setup - Get Free API Key

## 🧠 **Added AI Brain with RAG System!**

I've integrated a proper AI brain that uses:
1. **Hugging Face AI API** (free) for intelligent answers
2. **RAG (Retrieval-Augmented Generation)** system as fallback
3. **Smart chunking** and relevance scoring

## 🔑 **Get Your Free API Key (2 minutes):**

1. **Go to:** https://huggingface.co/settings/tokens
2. **Sign up** (free account)
3. **Create a new token** (select "Read" permissions)
4. **Copy the token** (starts with "hf_")

## ⚙️ **Setup:**

1. **Open:** `script.js`
2. **Find line 209:** `'Authorization': 'Bearer hf_your_token_here'`
3. **Replace:** `hf_your_token_here` with your actual token
4. **Save the file**

## 🚀 **How It Works Now:**

1. **Primary:** Uses AI to understand your question and generate smart answers
2. **Fallback:** If AI fails, uses RAG system to find relevant text chunks
3. **Smart:** Extracts only the relevant part that answers your question
